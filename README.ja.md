# UNI2 Frame Meter

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

『UNDER NIGHT IN-BIRTH II Sys:Celes』のトレーニングモード向けフレームタイムラインです。両プレイヤーのフレームごとの行動状態をゲーム画面下部に表示し、発生、攻撃判定、硬直、硬直差、無敵、キャンセル可能時間を直感的に確認できます。

## デモ動画

[YouTubeで見る](https://youtu.be/O8JgjDnPLmE)

## 主な機能

- 2段表示：上段が1P、下段が2P。
- 発生、攻撃判定、硬直、行動不能時間を表示。
- キャンセル属性、無敵属性、有効な飛び道具を任意で表示。
- 同一フレームの複数属性を色のレイヤーで同時表示。
- 連続する色区間のフレーム数を自動表示。
- 両者が行動可能になった後も結果を保持し、操作を止めて確認可能。
- 独立した透明オーバーレイを使用し、ゲームファイルやゲームメモリを変更しません。

## 動作環境

- Windows 10 または Windows 11
- Steam版 UNDER NIGHT IN-BIRTH II Sys:Celes
- ウィンドウまたはボーダーレス表示モード

特定のゲームバージョンには固定されていません。新キャラクター、バランス調整、技データの更新では通常ツールの更新は不要です。互換性のないエンジン変更が発生した場合は、無効なデータを読み続けず、エラーを表示して停止します。

## インストールと使用方法

1. リリースパッケージをダウンロードして展開します。
2. 次の2ファイルを同じフォルダーに置きます：

```text
UNI2FrameMeter.exe
frame_semantics.json
```

3. ゲームを起動してトレーニングモードに入ります。
4. `UNI2FrameMeter.exe` をダブルクリックします。
5. ゲームへ戻ると、ゲーム画面下部にタイムラインが表示されます。

タイムラインはゲームが前面にあり、最小化されていない間だけ表示されます。`UNI2 Frame Display` コントロールウィンドウを閉じるとツールも終了します。

## タイムラインの読み方

- 上段が1P、下段が2Pです。
- 1マスがゲーム内の1フレームです。
- 最後に記録されたマスの右端を白い線で示します。
- 第1色が連続している間、そのフレーム数を1Pは上、2Pは下に表示します。
- 両者が行動可能で、有効な飛び道具もない場合、タイムラインを停止して結果を保持します。
- 短い停止後に再び行動すると、経過時間は黒いマスになり、2つの行動を直接つなぎません。
- デフォルトでは60F連続で何も起きないと、次の行動から左端で新しい記録を開始します。
- タイムラインが満杯になると循環し、黒い間隔で新旧の内容を区別します。

基本色は行動不能、発生、攻撃判定、硬直を表します。キャンセル、無敵、飛び道具などの追加属性は同じマス内にレイヤー表示されます。色は設定ファイルで変更できます。

## コントロールウィンドウ

ツールを起動すると小さなコントロールウィンドウが開きます。項目をチェックまたは解除すると、その属性をすぐに表示・非表示にできます。

- 変更はすぐに反映されます。
- 選択内容は `frame_semantics.json` に自動保存されます。
- グレーの項目は現在利用できず、有効にできません。
- コントロールウィンドウを閉じるとタイムラインも終了します。

## 設定ファイルの編集

`frame_semantics.json` はプログラムと同じフォルダーにあります。標準JSON形式です。ツールを終了してから編集し、変更前にバックアップを作成することを推奨します。

### タイムライン設定

```json
"timeline": {
  "length_frames": 120,
  "idle_reset_frames": 60,
  "wrap_gap_frames": 5,
  "max_width_pixels": 1440,
  "current_frame_border_color": "#ffffff",
  "show_primary_run_counts": true,
  "primary_run_count_color": "#ffffff",
  "primary_run_count_font_size": 9
}
```

- `length_frames`：タイムラインのマス数。
- `idle_reset_frames`：次の行動を新しい記録にするまでの空きフレーム数。
- `wrap_gap_frames`：循環時に新旧の内容を分ける黒いマス数。
- `max_width_pixels`：タイムラインの最大幅。
- `current_frame_border_color`：最新フレームのマーカー色。
- `show_primary_run_counts`：連続区間のフレーム数表示を有効にします。
- `primary_run_count_color`：フレーム数文字の色。
- `primary_run_count_font_size`：フレーム数文字の大きさ。

### 色と順序の変更

各状態は `tokens` 内で定義されています：

```json
"attack": {
  "order": 50,
  "color": "#f0ad38"
}
```

- `color` は `#RRGGBB` 形式です。
- `order` が小さいほど、マス内の上側に表示されます。
- 存在しない属性や非表示の属性は空のレイヤーを残しません。

### 任意表示項目

任意項目は `external_attributes` にあります：

```json
{
  "token": "full_invincible",
  "display": true,
  "status": "confirmed",
  "description": "..."
}
```

- `display` を `true` にすると表示、`false` にすると非表示になります。
- `status` が `confirmed` の項目は変更できます。
- `status` が `incomplete` の項目は現在有効にできません。
- `description` は説明用であり、変更する必要はありません。

これらの `display` 設定はコントロールウィンドウからも直接変更できます。

## よくある問題

### タイムラインが表示されない

- トレーニングモードに入っていることを確認してください。
- ゲームが前面にあり、最小化されていないことを確認してください。
- 排他フルスクリーンではなく、ウィンドウまたはボーダーレスを使用してください。
- `frame_semantics.json` がEXEと同じフォルダーにあることを確認してください。

### ゲーム更新後に動作しない

通常のキャラクター追加やバランス調整は問題になりません。現在のゲーム構造を認識できないというエラーが表示された場合は、互換性更新をお待ちください。報告にはゲームのバージョンと完全なエラー内容を添えてください。

### Windowsのセキュリティ警告が表示される

署名されていない個人配布プログラムはSmartScreenの警告を表示する場合があります。本プロジェクトの正式なリリースページからのみダウンロードし、公開されているSHA-256と照合してください。

## 安全性と免責事項

本ツールは外部の読み取り専用オーバーレイです。DLLを注入せず、ゲームファイルやゲームメモリを変更しません。トレーニングモードでの使用を推奨します。
